# Caffe Framework for MIPS EV6x Processors

![Logo Caffe](images/logo-caffe.png)

## Overview

MIPS-Caffe is a modified version of the popular Caffe Machine Learning
framework adapted for use in embedded applications on MIPS ARC
EV6x Processors.
